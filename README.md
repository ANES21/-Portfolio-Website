## 🚀 Featured Projects

### 1. 📖🕌 Zad Al-Muslim (زاد المسلم)
A fast, responsive Islamic web platform and Android companion delivering daily essential utilities wrapped in a modern Glassmorphism UI.
- **Key Features:** Dynamic prayer times via Geolocation API, Uthmani script Quran display with audio recitation, and Taharah guides.
- **Tech Stack:** HTML5, CSS3, JavaScript (ES6+), Java, Android SDK, Aladhan API, Al Quran Cloud API.
- 🌐 [Live Demo](https://zad-al-muslim-two.vercel.app/) | 🔗 [Web Repo](https://github.com/ANES21/Zad-Al-Muslim) | 🔗 [Android Repo](https://github.com/ANES21/Zad-Al-Muslim-android-) | 📥 [Download APK](apk/Zad.apk)

### 2. 🕌 Quran Association Management System (منظومة إدارة جمعية تحفيظ القرآن الكريم)
A secure management system built for *El-Ma'ali Association* (Mellakou Branch) to digitize Quranic study circles, student tracking, and administrative operations.
- **Key Features:** Group management, daily ورد tracking, real-time financial accounting, and JWT-secured authentication.
- **Tech Stack:** HTML5, Tailwind CSS, JavaScript (Async/Fetch), Node.js, Express.js, Supabase (PostgreSQL).
- 🔗 [GitHub Repository](https://github.com/ANES21/WEB-For-the-Quran-Memorization-Society)

### 3. 📚 Bookanes App
An Android application acting as a digital library and note-taking tool designed around the Model-View-Adapter (MVA) pattern.
- **Key Features:** Visual catalog with RecyclerView grid, custom dialogs for instant note management, and offline SQLite storage.
- **Tech Stack:** Java, Android SDK, XML, SQLite Database.
- 📥 [Download APK](apk/app-debug.apk) | 🔗 [GitHub Repository](https://github.com/ANES21/BOOK-ANES)

### 4. ⚡🤖 Mujeeb AI (مُجيب)
An interactive AI assistant application powered by Express.js and Groq SDK to integrate with the ALLAM-2-7B model.
- **Key Features:** System prompt personality switcher, bilingual Text-to-Speech (TTS), quick action tools, and chat transcript export (.txt).
- **Tech Stack:** Node.js, Express.js, Groq API (ALLAM-2-7B), HTML5, CSS3, JavaScript (ES6+).
- 🌐 [Live Demo](https://mujeeb-ai-xi.vercel.app/) | 🔗 [GitHub Repository](https://github.com/ANES21/Mujeeb-AI)

### 5. 🏋️‍♂️⚽ USM App - Sports Club Management
An Android mobile application built for sports clubs to manage athlete records and monthly subscriptions.
- **Key Features:** Athlete registration, subscription billing tracking, interactive list view via RecyclerView with relational queries (`LEFT JOIN`), and cascading deletions.
- **Tech Stack:** Java, Android SDK, Material Design Components, SQLite Database.
