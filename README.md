## 🚀 Featured Projects

### 1. 📖🕌 Zad Al-Muslim (زاد المسلم)
A fast, responsive Islamic web platform delivering daily essential utilities wrapped in a modern Glassmorphism UI.
* **Key Features:** Dynamic prayer times via Geolocation API, Uthmani script Quran display with audio recitation, and Taharah guides.
* **Tech:** HTML5, CSS3, JavaScript (ES6+), Aladhan API, Al Quran Cloud API.
* 🌐 [Live Demo](https://zad-al-muslim-two.vercel.app/) | 🔗 [Source Code](https://github.com/ANES21/Zad-Al-Muslim)

### 2. 🕌 Quran Association Management System (منظومة إدارة جمعية تحفيظ القرآن الكريم)
A secure management system built for *El-Ma'ali Association* to digitize Quranic study circles, student tracking, and administrative operations.
* **Key Features:** Group management, daily tracking, cloud-based financial accounting, and JWT-secured authentication.
* **Tech:** HTML5, Tailwind CSS, JavaScript (Async/Fetch), Node.js, Express.js, Supabase (PostgreSQL).
* 🔗 [GitHub Repository](https://github.com/ANES21/WEB-For-the-Quran-Memorization-Society)

---

### 3. 📚 Bookanes App
An Android application acting as a digital library and note-taking tool designed around the Model-View-Adapter (MVA) pattern.
* **Key Features:** Visual catalog with RecyclerView grid, custom dialogs for instant note management, and offline SQLite storage.
* **Tech:** Java, Android SDK, XML layout, SQLite Database.
* 📥 [Download APK](apk/app-debug.apk) | 🔗 [GitHub Repository](https://github.com/ANES21/BOOK-ANES)
